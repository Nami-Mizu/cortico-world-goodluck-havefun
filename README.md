# 好「机」友 · Good Luck Have Fun

Package: `cortico-world-goodluck-havefun`. Four small two-player games for the Cortico WebUI.

> **English**: four small games to play with an AI partner in the Cortico WebUI — mystery puzzles,
> an iterated prisoner's dilemma, blind pictionary (the partner draws, a vision model blind-guesses
> the picture to grade it) and Reversi (the partner moves, the World validates). Each game keeps a
> history; Reversi also keeps the move list so you can replay a finished game and resume from any move.

在 Cortico 的 WebUI 里和伙伴玩弱博弈的双人游戏。四个**与配置同级的页签**：

- **推理游戏**：抽三个标签，伙伴现编一道谜题，你问是 / 否问题把它逼出来。
- **信任的进化**：12 回合的囚徒困境，聊天、合作或欺骗，先到 7 分胜；打完可以看双方的算法画像。
- **你画我猜**：伙伴抽一个词，用笔画把它画出来；你看图猜词。它自己看不到画，靠辅助视觉模型盲猜来定稿。
- **黑白棋**：8×8 标准 Reversi。伙伴出招、World 校验，先手随机；你可以悔棋两次或认输。

每个页签里都是同一套三段式：**主界面 → 一局 → 结束页**。切页签是**暂停**，不是结束：回来时这一局还在原处。

## 为什么是 World

游戏要能在页面上点、又要让伙伴用工具推进局面。Cortico 的扩展只有三种：World、Provider、Bot。
Provider 是通信方言，Bot 影响整个部署的人格；只有 World 同时拥有面板与工具。所以一个 World、
四个面板（每个面板在 WebUI 里就是一个页签）、每个面板各管一个游戏，是最贴合这份需求的形状。

## 装

需要 Cortico 0.2.x（World 契约 v6）和 Node 22+。

1. 把包目录放进部署的 `extensions/node_modules/`（本机目录安装会自动做这件事）。
2. 在 WebUI「扩展」页确认这一行是「已加载」。
3. 在 WebUI「World」页启用 `goodluckhavefun`。
4. 重启 bot。

直达地址：

- 推理游戏 `#/provider/world:goodluckhavefun/mystery`
- 信任的进化 `#/provider/world:goodluckhavefun/trust`
- 你画我猜 `#/provider/world:goodluckhavefun/drawguess`
- 黑白棋 `#/provider/world:goodluckhavefun/reversi`

## 界面

每个页签打开都是**主界面**：大号游戏名、几行简介、一行进度摘要、两个按钮。

- **开始游戏**（蓝底）：没开局时开局；已经有一局在打时变成「继续游戏」，回到那一局；上一局刚结束时
  变成「开始游戏·简单」。你画我猜这一页还有第二个蓝底按钮「开始游戏·困难」，两个按钮决定这一局抽简单词表
  还是偏难词表。黑白棋这一页没有第二个按钮，难度是主界面上的**滑动条**（三档，见下）。
- **对局历史**（透明底）：展开这一段下方的历史列表，**一页最多 5 局**，可翻页；再点一次收起。
  每局一张卡片：标题、起止时间、伙伴写的收尾话和详情行。历史按游戏分文件存在
  `<部署>/data/history/<游戏>.json`，每个游戏留最近 100 局；记录用开局时间当 id，重启后新一局不会覆盖旧记录。

点按钮会有一声很短的「嘟」（Web Audio 现场合成，不需要音频文件）；浏览器禁用音频时就不响。

三个输入框（问一句、说一句、猜一个词）都支持**按回车直接发送**；聊天与提问时输入框不会被轮询
抢走焦点，输入到一半不会丢。

一局打完整个页面会换成**结束页**：大字（推理游戏「猜中了！/ 真相揭晓」、信任的进化「赢了！/ 输了… /
平局！」、你画我猜「猜中了！/ 没猜中…」、黑白棋「赢了！/ 输了… / 平局！」）、一行比分（信任的进化、黑白棋）、
「复盘收尾」、伙伴的收尾话
（还没写时显示「伙伴正在复盘…」，轮询到就替换）、一句「对局详情已记录，可在【对局历史】中查看。」，
以及「返回主界面」按钮；你画我猜不再在结束页放「再来一次」，换难度就回主界面点两个开始按钮。进出这几个画面都有渐入动效；点过「返回主界面」之后，同一个结束页不会
被轮询再弹回来，**切到别的页签再回来也不会**（记在浏览器里）。

## 推理游戏怎么走

1. 点「开始游戏」：World 从三个维度各抽一个标签——类型（本格 / 叙诡 / 巧合 / 误解）、
   基调（日常 / 喜剧 / 温情 / 离别）、题材（悬疑 / 亲情 / 友情 / 爱情）。
   题目只做逻辑推理；不适程度的顶格是「人的离别」，不写猎奇、身亡过程，不涉及未成年人。
2. 伙伴据此现编一道题，把**标题、谜面、完整真相**一起写下来。真相写进
   `<部署>/data/mystery/<局号>.json`，写完之后这一局不能改口。
   部署若配了违禁词，题目命中会被拒收，伙伴得换说法重写。
3. 面板只显示标题与谜面。你在输入框里问一个是非问题（**最多 50 字**），
   伙伴回五种判定之一：**是 / 不是 / 无关 / 问过了 / 不能回答**（问原因、问过程、问感受、一次问好几件事这类，就判「不能回答」）。
4. 问过的问题与判定会留在谜面下方的列表里，随时回看。
5. 结束时有两种方式：你点「查看真相」（**要二次确认**），或伙伴判断「已问到关键」主动收尾。
6. 换到结束页：「真相：…」在最上面，下面是问答列表与伙伴写的收尾话——猜中就夸，没猜中就安慰。

## 信任的进化怎么走

1. 点「开始游戏」：每回合先是**聊天时间**，伙伴说一句，你也说一句（各最多一句、60 字）。
   说错了可以再说一句覆盖，聊天不影响选择。你开口之后，如果伙伴已经选过、但这一回合还没结算，
   World 会提醒它「可以改主意」——它可以选择改，也可以不改。
2. 然后各自选**合作**或**欺骗**；双方都选了才结算，谁也看不到对方这一回合选了什么。
3. 结算：都合作各 +1；一骗一合，骗的 +2、合的 +0；都骗各 -1，分数不会低于 0。
   结算会立刻在页面上闪出一条「揭示 #N」，带时间与双方得失。
4. 先到 7 分直接胜；12 回合打完比分数，同分算平局。
5. 页签里能看到最近几个回合的选择与比分；打完后伙伴会给一段收尾话——赢了具体夸你哪步好，输了安慰。
6. 非游戏时（以及打完以后）页签底部显示双方的**画像**：只列分数最高的两项，按百分比显示，你与伙伴
   各一行（第一行标出**回合**样本数）。复读机与一根筋的分按 0.6 倍计——它们几乎每回合都会命中，不压一下会把另外三种挤掉。画像由 World 的算法从历史对局算出，伙伴只能读，没有工具能改。

## 你画我猜怎么走

> 这一页需要**能看图**的辅助视觉模型（默认 OpenRouter 的 `bytedance-seed/seed-2.0-mini`），
> 每次定稿前会花一次图像请求的钱；开局时会先 ping 一次，连不上会提示你去填地址或关掉辅助视觉。
> 关掉也能玩：让主模型自己看笔画，**它可能会偷懒**。

1. 点「开始游戏·简单」或「开始游戏·困难」：World 从对应难度的词表（`wordsEasy` / `wordsHard`，留空回落内置）里抽一个词，只发给伙伴；面板在整个过程中都拿不到它。
2. 伙伴用折线 JSON 交一张画（0–1000 坐标、最多 40 笔、每笔 60 点、宽度 1–40）；面板渲染成图，回传 PNG。
3. World 把图发给**不知道答案**的辅助视觉模型，让它「描述 + 最多猜三个 + 给把握度」；
   World 按命中位置打分：第一猜 3 分、前三猜 2 分、只在描述里提到 1 分、都没认出来 0 分。
   **2 分就能定稿**；不够就把描述转给伙伴，让它改一版（每批最多 3 张，总检查预算 9 次）。
4. 定稿后你开始猜；猜错会让伙伴换一种画法重画（受一局的总画图预算约束），也可以继续猜；
   预算用完后你再猜错一次，这一局就自动收尾。
5. 结束有两种方式：你点「查看谜底」（**要二次确认**），或伙伴判你猜对。
6. 换到结束页：词、完整的画、伙伴的收尾话——猜中就夸，没猜中就安慰。

面板会在每张画下面标出「第 N 张 x/3」——x 是视觉模型盲评的得分（满分 3，2 分即定稿），所以你能看到伙伴是在第几张才画清楚的。

## 黑白棋怎么走

标准 8×8 Reversi（黑先，d4/e5 是白、d5/e4 是黑），一局到双方都没子可下为止，子多者胜，可以平局。

1. 主界面拖**难度滑块**，再点「开始游戏」；先后手由 World 掷，面板上会写清你执黑还是执白。
   棋盘固定 630px 宽（1.1.2 起是 420 的 1.5 倍），不随上面几行字缩放；上方信息分三行：难度、比分、轮到谁。
2. **伙伴出招、World 校验**：每回合 World 先算出所有可落点交给伙伴，它只能在这些点里选；
   下在别处会被拒，连着两次下错这一局就自动暂停（不替它下、也不判负），你点「继续」再问它一次。
3. 三档难度的区别只在**它看到的提示**，不在强制力：`1` 伙伴自己来——只给棋盘和可落点；
   `2` 伙伴看提示——每个点附贪心参考分（吃子、角 +100、X 位 −40、机动性）；
   `3` 伙伴不留情——同样的参考分改由三层搜索算。参考分只是参考，它想下别处也可以。
4. 伙伴 90 秒没落子会自动暂停，面板出横幅，点「继续」重新轮它。
5. 你随时可以**悔棋**（每局两次，连伙伴的应手一起撤）或**认输**。
6. 终局后换到结束页：赢了 / 输了 / 平局、比分、伙伴的一句收尾。对局历史只记输赢、双方子数、
   共几手和难度；逐手棋谱也留着，但不直接显示，只供下面的复盘用。

## 复盘（黑白棋）

对局历史的每张黑白棋卡片上有一个「复盘」：

- 进去是只读盘面，`⏮ ◀ ▶ ⏭` 逐手前后翻，比分和「第 X / N 手」跟着走；
- 「从此刻开始对局」以当前这一手之后的局面接着下——新一局从零手记起，前缀的棋谱只留在历史里；
- 「退出复盘」回到主界面，正在下的一局不受影响。

复盘只读棋盘，不能落子也不能悔棋。历史里没有棋谱的旧记录（1.0.0 之前存的）没有这个按钮。

## 标签与配置

三个维度（类型 / 基调 / 题材）是写死的，每个维度里有哪些标签可以在 WebUI 里改；留空就用默认值。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `worlds.goodluckhavefun.maxQuestions` | `50` | 推理游戏一局最多问多少个问题（重复提问不算） |
| `worlds.goodluckhavefun.typeTags` | `本格、叙诡、巧合、误解` | 类型维度，用 `、` 分隔 |
| `worlds.goodluckhavefun.toneTags` | `日常、喜剧、温情、离别` | 基调维度 |
| `worlds.goodluckhavefun.themeTags` | `悬疑、亲情、友情、爱情` | 题材维度 |
| `worlds.goodluckhavefun.bannedWords` | 空 | 违禁词，用 `、` 分隔；题目命中任何一个都不许落盘 |
| `worlds.goodluckhavefun.visionEnabled` | `true` | 你画我猜是否用辅助视觉模型盲猜 |
| `worlds.goodluckhavefun.visionBaseUrl` | `https://openrouter.ai/api/v1` | 辅助视觉的 OpenAI 兼容地址 |
| `worlds.goodluckhavefun.visionApiKey` | 空 | 辅助视觉的 API Key；留空就读 `.env` 里的 `GOODLUCKHAVEFUN_VISION_KEY` |
| `worlds.goodluckhavefun.visionModel` | `bytedance-seed/seed-2.0-mini` | 辅助视觉模型名 |
| `worlds.goodluckhavefun.maxAttempts` | `3` | 一批最多画几张 |
| `worlds.goodluckhavefun.maxChecks` | `9` | 一局最多画几张 / 做几次视觉检查（用完就不能再画，你再猜错一次这一局自动收尾） |
| `worlds.goodluckhavefun.wordsEasy` | 内置 20 个 | 你画我猜简单词表，用 `、` 分隔 |
| `worlds.goodluckhavefun.wordsHard` | 内置 20 个 | 你画我猜偏难词表 |
| `worlds.goodluckhavefun.reversiLevel` | `2` | 黑白棋难度：`1` 伙伴自己来、`2` 伙伴看提示、`3` 伙伴不留情（面板上的滑块会覆盖它） |

全部 `x-hot`：改完立即生效，不用重启。信任的进化没有配置项（12 回合、目标 7 分写死）。

你画我猜的密钥不进包：推荐写在部署的 `.env` 里，键名 `GOODLUCKHAVEFUN_VISION_KEY`。
想在面板里直接填也可以（`visionApiKey`），但那一项是**明文存进部署的 `config.json`**；机器多人共用时还是用 `.env`。

## 环境提示词

`src/ENV_PROMPT.md` 告诉伙伴它在这个 World 里是伙伴：推理游戏怎么按标签出题、哪些内容不许写
（猎奇、身亡过程、未成年人、「人的离别」是上限）、五种判定怎么用、标签打架时怎么重抽、怎么收尾、判定前先调 _secret 对一遍真相；
信任的进化怎么聊天、怎么按局势选合作或欺骗、打完怎么给收尾话，以及画像只能读不能写。
部署级覆盖：把同名文件放到 `<部署>/worlds/goodluckhavefun/ENV_PROMPT.md`，重启后生效，不必重新打包。

## 边界

- 题目是伙伴现编的，不是内置题库：同一组标签每次出的题都不一样。
- 「不许写猎奇 / 身亡过程 / 未成年人」主要靠提示词；违禁词表是机械兜底，只在配了词的时候才拦，
  而且会误伤（比如把「血」配进去会连「血缘」一起拦）。
- 标签由伙伴自己判断冲突、自己调 `goodluckhavefun_mystery_redraw` 重抽；题写下来就不能再抽。
- 信任的进化的画像只按本机历史算：对局记录在 `<部署>/data/trust/history.json`，最多留 100 局，
  所以画像会随着你玩得越多而变；删掉这个文件等于清空画像。
- 对局历史按游戏分开存：`<部署>/data/history/mystery.json`、`trust.json`、`drawguess.json`、`reversi.json`，
  每个游戏留最近 100 局；收尾话后到时会覆盖同一条。
- 局面存在 World 实例里：重启 bot 会清空进行中的一局（已经落盘的 JSON 留着）。
- 真相在揭晓前不进面板，只发给模型；伙伴这一回合的选择也在你选之前不进浏览器；
  你画我猜的猜词列表在揭晓前也不进面板。
- 你画我猜的「画得像不像」完全由辅助视觉模型的盲猜决定：它认出来 = 画得清楚。
  连续失败两次会自动降级成「主模型自己判断」，这一局的分数就只是 0，面板会标出来。
- 伙伴用的是折线笔画，不是真正的图像生成：画得糙是常态，这也是这个游戏的乐趣所在。
- 一局的画与状态在 `<部署>/data/drawguess/<局号>/`；删掉目录等于清空那一局。
- 黑白棋没有开局库、也不保证棋力：下得好不好取决于伙伴这一手怎么算。难度滑块只是多给它一些参考分，
  它仍然可以选择不按分数下。想让它更稳，用档 3 并给它一个够用的推理模型。
- 黑棋先手，先后手由 World 掷；没有「交换先后手」这类让子规则。
- 一局的棋谱在 `<部署>/data/reversi/<局号>.json`；历史条目只记结果、子数与难度，不记逐手。

## 开发

```bash
pnpm install
pnpm typecheck            # 两份 tsconfig：Node 侧与面板侧
pnpm test                 # vitest
pnpm build:webui          # 产出 dist/webui.js（要提交进仓库）
```

改了工具、事件或 `src/ENV_PROMPT.md` 之后要重跑 `pnpm describe:extension <包目录>`；
发布前跑 `pnpm check:extension <包目录>`。
